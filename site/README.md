# Phone Access

This folder contains the mobile-friendly market brief page.

## Main file

- `index.html`

## Ways to read it on your phone

### Option 1: cloud-synced file

If this workspace lives inside iCloud Drive, Dropbox, Google Drive, or OneDrive, you can open `site/index.html` directly from your phone.

### Option 2: lightweight hosting

Put this folder in a Git repo and publish it with GitHub Pages, Netlify, or Vercel for a normal mobile web URL.

### Option 3: manual local sharing

Serve the folder from your Mac on your local network and open it from your phone browser while both devices are on the same Wi-Fi network.

## Automation intent

The daily automation should refresh this page every weekday morning in the UK so the latest brief is always at `site/index.html`.
